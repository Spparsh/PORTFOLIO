# Spparsh Jawade — Portfolio

A responsive developer portfolio built with plain HTML, CSS and JavaScript.

## Run
Open `index.html` directly, or use VS Code Live Server.

## Before publishing
Search `index.html` and replace:
- `YOUR_EMAIL_HERE` with your email
- `href="#"` on GitHub and LinkedIn with your actual profile URLs
- Add a Resume PDF and link it from the hero if desired
- Add project GitHub/demo links to individual project cards if desired

## Deploy
This is a static site and can be deployed directly to GitHub Pages, Netlify or Vercel.
